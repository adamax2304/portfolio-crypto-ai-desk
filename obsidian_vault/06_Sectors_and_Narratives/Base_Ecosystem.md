# Base Ecosystem

## Status

**Not currently configured** in `config/watchlist.yaml.narratives`. Recommended addition.

## What usually moves this sector

- Coinbase Base TVL.
- AERO / Aerodrome dex volume.
- Base-native meme coins (BRETT, DEGEN, others).
- Coinbase consumer adoption news.

## What news matters

- Base mainnet improvements / fee changes.
- New dApp launches.
- Coinbase quarterly results / consumer growth.

## Telegram / social signals

- Strong Twitter presence, moderate Telegram.

## Best regime

- `bullish trend` with risk-on.
- Worst: `bearish trend` — Base alts often underperform.

## Indicators that matter most

- AERO RS as proxy for ecosystem.
- Base meme RS as proxy for retail interest.

## Common risk

- Many Base tokens are not on Binance — high probability of `not_on_anchor` cap (75) or MEXC-only cap (70).
- Liquidity often thin on smaller Base tokens.

## Common fake signals

- "Coinbase will list X" rumors (often unconfirmed).
- Generic "Base TVL flips L2" headlines.

## Scoring posture

- Once configured, would behave like L2 narrative.

## Example good setup

- AERO with positive RS, narrative hot, anchor (Binance) listed, no recent unlock.

## Example bad setup

- A Base meme only on MEXC, low liquidity, no derivatives data — capped at 60–65 by liquidity + MEXC-only.
