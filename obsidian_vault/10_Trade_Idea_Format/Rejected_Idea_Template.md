# Rejected Idea Template

Use to log a desk-rejected idea (`tier = rejected`) or an idea you personally rejected.

```
# Rejected — {{symbol}} — {{date}}

## Snapshot
- Symbol / direction bias:
- Mode (from the report):
- Score: {{score}}
- Primary reason: {{primary_reason from RejectedIdea}}
- Other reasons:
- Exchange list:
- Risk flags (mexc_only / not_on_anchor / no_derivatives_confirmation / price_divergence):

## Why the desk rejected
- Cap reasons (if any): {{cap_reasons}}
- Setup warnings:
- Risk warnings:
- Critic verdict (if any):

## Would I have taken it manually?
- Yes / No
- If yes, what was I seeing that the desk missed?
- If no, what aligned with my read?

## Follow-up
- Watch for upgrade? (yes / no)
- Notes for `manual_events.yaml` if a real catalyst materializes:
- Anything to file in [[Useless_News]] or [[Fake_or_Unverified_News]]?

## Outcome later (fill in next day)
- Did the symbol move as the bias suggested?
- Did the rejection save me from a loss?
- Or did I miss the move?
- Lesson:
```
