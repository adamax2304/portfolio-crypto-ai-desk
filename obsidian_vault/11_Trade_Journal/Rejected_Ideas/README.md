# Rejected_Ideas

Ideas the desk rejected with reason — or that you personally rejected.

## How files land here

- Manual: copy [[Rejected_Trade_Template]] and fill from the report's "Rejected ideas with reasons" block.
- Recommended automation: a script that imports every `RejectedIdea` from a given report.

## Filename

```
YYYY-MM-DD_SYMBOL_MODE_REJECTED_SCORE.md
```

## Why bother

The rejected dataset is **at least as informative** as the executed dataset. Patterns:

- Which rejection reasons coincide with outcomes you regret missing? (e.g. MEXC-only that ran 30%)
- Which rejection reasons consistently saved you? (e.g. extreme funding caps)
- Which sectors / venues get the most rejections in this regime?
