# Reviews

Daily, weekly, and per-idea review notes.

## File types

- **Daily review** — `YYYY-MM-DD_Daily_Review.md` (use [[Daily_Review_Template]]).
- **Weekly review** — `YYYY-Www_Weekly_Review.md` (use [[Weekly_Review_Template]]).
- **Per-idea review** — `YYYY-MM-DD_SYMBOL_Review.md` (use [[Review_Template]]).

## When to write

- Daily: every evening (or once per active trading session).
- Weekly: every Sunday.
- Per-idea: within 24h of trade close.

## Cross-references

- Link from each per-idea review back to the original Potential / Executed file.
- Link from Daily_Review back to all per-idea files for that day.
- Link from Weekly_Review back to that week's Daily_Review files.
