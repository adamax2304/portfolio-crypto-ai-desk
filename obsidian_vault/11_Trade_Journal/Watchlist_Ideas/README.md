# Watchlist_Ideas

C-tier ideas the desk surfaced. The desk's `WatchlistMonitor` is also auto-watching these for upgrade.

## How files land here

- Manual: copy [[Watchlist_Template]] and fill from the latest report's "Watchlist-only" block.

## Filename

```
YYYY-MM-DD_SYMBOL_MODE_WATCH_SCORE.md
```

## Lifecycle

- **Created** when the desk lists the name as C-tier with a directional setup.
- **Updated** when the desk's next report changes status or score.
- **Promoted to Potential_Trades** when the desk reports C → B/A upgrade.
- **Deleted or archived** when the C-tier setup becomes stale (≥ 1 week with no action).
