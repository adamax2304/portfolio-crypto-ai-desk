# Useful_News

News items that created or confirmed a tradable setup.

## Criteria

- Verified via at least primary or multi-source.
- Produced a measurable price reaction in the news direction within a reasonable window.
- Created or supported an idea you (or the desk) acted on.

## How files land here

- Originally created in `Telegram_News/` or as a manual note.
- Promoted to this folder after the price / time reaction window passes.

## Filename

```
YYYY-MM-DD_HHMM_SOURCE_SYMBOL_SHORT-SLUG.md
```

## What to capture in each file

Use [[Useful_News_Template]] or extend [[News_Item_Template]] with a "Why this was useful" block.
