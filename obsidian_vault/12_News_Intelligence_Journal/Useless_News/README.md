# Useless_News

Items that did not move price and did not create a setup.

## Criteria

- < 1% move within 60 minutes on the named symbol.
- No volume_ratio spike (≥ 1.5).
- No OI / funding shift correlated with the headline.
- No trade resulted, neither for you nor for the desk.

## Why log noise

- The dataset is half the value. Without noise data, you can't compute hit rates per source.
- A pattern emerges: which channels / categories / time-of-day produce consistent noise.

## File hygiene

- Keep entries short. Don't burn time documenting noise.
- Use [[Useless_News_Template]] — it's intentionally minimal.
