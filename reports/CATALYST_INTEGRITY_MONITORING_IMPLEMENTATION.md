# Catalyst Integrity Monitoring — Implementation (PART 7)

**Date:** 2026-06-17 · **Verdict:** **CATALYST_INTEGRITY_MONITORING_READY**
**Mode:** read-only monitoring after the ASTER label fix. **No trade promotion, no scoring change.**

## What was built
- **`src/catalysts/integrity.py`**
  - `catalyst_integrity_for_signal(conn, signal, …)` — per-candidate payload fields; probes that `news_items` exists first so a missing table reports **`unknown`** (honest), not a fake "no catalyst".
  - `scan_catalyst_integrity(conn, now, …)` — daily summary: counts high-importance symbol-tagged news, the catalyst-symbol set, cross-checks today's `catalyst_events.jsonl` (mapped vs unmapped) and `narrative_baskets.jsonl` (no-catalyst baskets containing direct-news symbols = the regression signature). Artifact-derived numbers are `None` (not faked) when artifacts are absent.
- **`scripts/catalyst_integrity_scan.py`** — read-only runner that writes `reports/CATALYST_INTEGRITY_DAILY_SUMMARY.md` + prints a warning line (Telegram-hook ready). Safe to schedule after the catalyst-scan step.
- **Per-signal wiring:** `catalyst_integrity_status` / `direct_news_items_checked` / `catalyst_mapping_confidence` flow into the paper-entry payload via `assemble_risk_guard_fields`.

## Fields / outputs
Per signal: `catalyst_integrity_status` (catalyst_backed_confirmed / no_direct_news_catalyst / unknown), `direct_news_items_checked`, `catalyst_mapping_confidence`.
Daily: high_importance_symbol_tagged, catalyst_symbols, mapped_event_symbols, unmapped_high_importance_*, no_catalyst_basket_news_hits, warning(s), status, confidence.
