## Required Output Format

Every trade idea card must include:

- symbol (e.g. SOL/USDT)
- mode (scalp / intraday / swing)
- direction (long / short / watchlist / no_trade)
- tier (A / B / C / rejected)
- score + confidence + data_confidence
- exchange focus (binance / bybit / mexc)
- market regime alignment
- entry zone
- invalidation (timeframe close beyond level)
- targets (TP1 / TP2 / TP3)
- thesis (1 paragraph)
- key evidence (3–6 bullets)
- Telegram / news impact (verified / single_source / rumor)
- counter-thesis (1–3 bullets)
- do-not-enter conditions
- monitoring checklist
- caps active (or `none`)
- logging destination (vault folder + filename)

Finish with: compact trade table, risk warnings, what to monitor next, weak/missing data, logging actions taken.
